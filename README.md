# projects-digital-design
University projects and assignments on the subject of digital design


Στο εξής repository βρίσκονται εργασίες και project του πανεπιστημίου μου στο μάθημα "Ψηφιακή Σχεδίαση" Σε όλες τις εργασίες, ο βαθμός ήταν προβιβάσιμος.
Οι εργασίες υλοποιήθηκαν μέσω του λογισμικού προσομοίωσης Logisim-Evolution.

Συνολικά εκπονήθηκαν 5 εργασίες.

Κύρια θέματα των εργασιών εν συντομία:
1) Λογικές πύλες NOT, OR, XOR, AND, NAND, NOR, 
2) Ημιαθροιστής, πλήρης αθροιστής, ημιαφαιρέτης, πλήρης αφαιρέτης, κύκλωμα πράξεων 4bit με επιλογή πρόσθεσης ή αφαίρεσης
3) Μανταλωτής, R-S Flip-Flop, D Flip-Flop, J-K Flip-Flop, διπλό J-K Flip-Flop
4) Καταχωρητής δεξιάς ολίσθησης, καταχωρητής 8bit
5) Αύξων ασύγχρονος δυαδικός μετρητής 4bit, μετρηρής μεταβλητού υπόλοιπου


Σημείωση: Οι εργασίες αναπτύχθηκαν κατά το 2ο εξάμηνο σπουδών.
